The Address

Eight corners are the eight 3-bit addresses.

← The Shells The Lines →

LIT Bits 0, 1, and 2 set the coordinates x, y, and z to 0 or 6. The eight values 0 through 7 produce eight distinct corners, and there are no others.

AMBER The eight appeals are seated on these addresses in bit order. The seating is assigned.

WALL A bit address is not a postal address, and an appeal's name is not evidence about that appeal's tradition.
