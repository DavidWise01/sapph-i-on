THE EIGHT-CASE RULEBOOK

a single row, an 8-bit rule, and a universe below it

THE RULE

Each cell sees itself and its two neighbours, 8 possible cases, and an 8-bit rule number gives the next state for each. Live cells are coloured by the case (q.d) that made them.

Type any rule from 0 to 255. Tap to flip a cell in the current row. The same ?seed= always gives the same run.

WHAT IS CLAIMED

LITWolfram’s elementary cellular automata; rule 110 is universal (Cook, 2004). Cells must stay binary and the rule must stay in 0..255, or the page throws.
