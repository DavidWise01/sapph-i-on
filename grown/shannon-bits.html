WINNERShannon entropy (1948): H = −Σ p log₂ p bits per symbol. It counts how surprising a symbol is, given how often each one occurs.
CHALLENGERHartley’s measure (1928): log₂ N bits per symbol, treating all N symbols as equally likely. It is the upper bound that Shannon’s weighting tightens.
