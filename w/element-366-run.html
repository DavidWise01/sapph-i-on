Out to 366: where the rows close

Same method as the first build (element-168-build.html): each atom finds its own lowest-energy arrangement, with nothing assigned by a filling rule. This page runs from 169 to 366. Past Z ≈ 170 the innermost electron has dropped below the floor of empty space, so everything here is model-only: atoms this heavy cannot hold this form. AMBER throughout

Gold, silver and the Planck scale

Gold (79) and silver (47) are both a full d shell plus one s electron. In this run the matching atoms would be 211, 283 and 355 (a full d shell, then one s electron). They are not 218 or 362, so the electrum label has no number behind it yet. One real coincidence: 47 + 79 = 126, which is a closed-shell number for nuclei. AMBER
